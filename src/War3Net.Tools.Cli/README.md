# War3Net.Tools.Cli

## About

War3Net.Tools.Cli is the source for **`w3n`**, a command-line tool that exposes War3Net's Warcraft III modding libraries for scripting, CI, or terminal use. It is part of the [War3Net](https://github.com/Drake53/War3Net) modding library.
