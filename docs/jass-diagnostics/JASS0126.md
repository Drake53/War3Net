## JASS0126: Return Value Required

| Property       | Value               |
|----------------|---------------------|
| **ID**         | JASS0126            |
| **Descriptor** | ReturnValueRequired |
| **Category**   | Semantic            |
| **Severity**   | Error               |

### Cause

This diagnostic is triggered when a bare `return` statement appears in a function that declares a return type.

### Rule description

A function declared with `returns <type>` must return a value of that type on every return statement.

### How to fix violations

Return a value of the declared type, or change the function to `returns nothing` if the function should not return a value.

### Example

```jass
function GetValue takes nothing returns integer
    return
//  ^^^^^^ JASS0126: A return value of type 'integer' is required
endfunction
```

Fixed code:

```jass
function GetValue takes nothing returns integer
    return 0
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Every `return` statement in a value-returning function must provide a value.
