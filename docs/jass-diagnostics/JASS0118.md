## JASS0118: Wrong Symbol Kind

| Property       | Value           |
|----------------|-----------------|
| **ID**         | JASS0118        |
| **Descriptor** | WrongSymbolKind |
| **Category**   | Semantic        |
| **Severity**   | Error           |

### Cause

This diagnostic is triggered when a symbol is used as a different kind than what it was declared as. This includes:
- Calling a variable, type, or constant as if it were a function
- Using the `function` keyword to reference a variable, type, or constant
- Assigning to a function or type name as if it were a variable
- Using array access on a function or type name
- Declaring a type where the base type is a variable or function name

### Rule description

In JASS, each declared name has a specific kind — function, variable, parameter, or type — and can only be used in ways appropriate to that kind:
- Only functions and natives can be called or referenced with the `function` keyword
- Only variables and parameters can be assigned to
- Only variables can be used with array access
- Types cannot be used as functions or variables

### How to fix violations

1. Use the correct name for the intended kind of symbol
2. Check for name conflicts between functions and variables
3. When using `function` keyword, ensure the identifier refers to a declared function or native

### Example

Calling a variable as a function:

```jass
globals
    integer MyValue = 5
endglobals

function MyFunction takes nothing returns nothing
    call MyValue(10)
    //   ^^^^^^^ JASS0118: 'MyValue' is a variable but is used like a function
endfunction
```

Assigning to a function name:

```jass
function MyFunc takes nothing returns nothing
endfunction

function main takes nothing returns nothing
    set MyFunc = 5
    //  ^^^^^^ JASS0118: 'MyFunc' is a function but is used like a variable
endfunction
```

Code variable (cannot be directly invoked):

```jass
function DoWork takes nothing returns nothing
endfunction

function MyFunction takes nothing returns nothing
    local code myFunc = function DoWork
    call myFunc()
    //   ^^^^^^ JASS0118: 'myFunc' is a variable but is used like a function
endfunction
```

Fixed code:

```jass
function DoWork takes nothing returns nothing
endfunction

function MyFunction takes nothing returns nothing
    call DoWork()
endfunction
```

Function reference to variable:

```jass
globals
    integer MyValue = 5
endglobals

function MyFunction takes nothing returns nothing
    local code c = function MyValue
    //                      ^^^^^^^ JASS0118: 'MyValue' is a variable but is used like a function
endfunction
```

Function reference to type:

```jass
type myhandle extends handle

native TakeCode takes code c returns nothing

function MyFunction takes nothing returns nothing
    call TakeCode(function myhandle)
    //                     ^^^^^^^^ JASS0118: 'myhandle' is a type but is used like a function
endfunction
```

Array access on a type:

```jass
type myhandle extends handle

function main takes nothing returns integer
    return myhandle[0]
    //     ^^^^^^^^ JASS0118: 'myhandle' is a type but is used like a variable
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed.
