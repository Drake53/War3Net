## JASS1627: Invalid Debug Statement

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS1627              |
| **Descriptor** | InvalidDebugStatement |
| **Category**   | Syntax                |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when the `debug` keyword is applied to a statement type that doesn't support it.

### Rule description

In JASS, the `debug` keyword can only be applied to specific statement types:
- `call` statements: `debug call MyFunction()`
- `set` statements: `debug set x = 5`
- `if` statements: `debug if condition then ... endif`
- `loop` statements: `debug loop ... endloop`

The `debug` keyword cannot be applied to:
- `return` statements
- `exitwhen` statements
- `local` declarations
- another `debug` statement

Debug statements are only executed in debug mode and are stripped from release builds.

### How to fix violations

1. Remove the `debug` keyword if the statement must always execute
2. Wrap the statement in a `debug if true then ... endif` block
3. Use a supported statement type

### Example

```jass
function MyFunction takes nothing returns integer
    debug return 5
    // ^^^^^^^^^^^ JASS1627: 'debug' can only be applied to 'call', 'set', 'if', or 'loop' statements
endfunction
```

Fixed code (remove debug):

```jass
function MyFunction takes nothing returns integer
    return 5
endfunction
```

Debug local:

```jass
function MyFunction takes nothing returns nothing
    debug local integer x = 5
    // ^^^^^^^^^^^^^^^^^^^^^^ JASS1627: 'debug' can only be applied to 'call', 'set', 'if', or 'loop' statements
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer x
    debug set x = 5
endfunction
```

Debug exitwhen:

```jass
function MyFunction takes nothing returns nothing
    loop
        debug exitwhen true
        // ^^^^^^^^^^^^^^^^ JASS1627: 'debug' can only be applied to 'call', 'set', 'if', or 'loop' statements
    endloop
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    loop
        debug if true then
            exitwhen true
        endif
    endloop
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Use supported statement types with `debug`.
