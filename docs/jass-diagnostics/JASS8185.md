## JASS8185: Local Declaration Must Appear First

| Property       | Value                           |
|----------------|---------------------------------|
| **ID**         | JASS8185                        |
| **Descriptor** | LocalDeclarationMustAppearFirst |
| **Category**   | Semantic                        |
| **Severity**   | Error                           |

### Cause

This diagnostic is triggered when a local variable declaration appears after other statement types within a function body.

### Rule description

In JASS, all local variable declarations must appear at the beginning of a function body, before any other statements. Once a non-declaration statement (such as `call`, `set`, `if`, `loop`, or `return`) is encountered, no further local variable declarations are permitted. Declarations inside nested blocks (loops, if/else) are also not allowed.

### How to fix violations

1. Move all local variable declarations to the top of the function body
2. If the variable depends on runtime state, declare it at the top and assign it later with a `set` statement

### Example

```jass
function Foo takes nothing returns nothing
    call DoSomething()
    local integer x
    //            ^ JASS8185: Local variable declaration must appear at the start of the function body
    set x = 5
endfunction
```

Fixed code:

```jass
function Foo takes nothing returns nothing
    local integer x
    call DoSomething()
    set x = 5
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed.
