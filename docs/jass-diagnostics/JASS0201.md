## JASS0201: Missing Statement

| Property       | Value            |
|----------------|------------------|
| **ID**         | JASS0201         |
| **Descriptor** | MissingStatement |
| **Category**   | Syntax           |
| **Severity**   | Error            |

### Cause

This diagnostic is triggered when a statement is expected but none is found.

### Rule description

A JASS statement must begin with one of the statement keywords, such as `set`, `call`, `local`, `if`, `loop`, `return`, or `exitwhen`. When a statement is expected but the input begins with none of them, this error is reported.

### How to fix violations

1. Begin the statement with a valid statement keyword
2. Remove the stray tokens if no statement was intended

### Example

```jass
5 + 3
// ^^ JASS0201: Statement expected
```

Fixed code:

```jass
call BJDebugMsg(I2S(5 + 3))
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. A valid statement must be provided.
