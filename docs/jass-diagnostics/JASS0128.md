## JASS0128: Duplicate Local Declaration

| Property       | Value                     |
|----------------|---------------------------|
| **ID**         | JASS0128                  |
| **Descriptor** | DuplicateLocalDeclaration |
| **Category**   | Semantic                  |
| **Severity**   | Error                     |

### Cause

This diagnostic is triggered when a local variable is declared with the same name as another local variable or parameter in the same function.

### Rule description

In JASS, each local variable within a function must have a unique name. This includes:
- Local variables declared with `local`
- Function parameters

Note: Local variables can shadow global symbols, but cannot duplicate other locals or parameters in the same function.

### How to fix violations

1. Rename one of the duplicate local variables
2. Remove the duplicate declaration if it's unintentional
3. Use the existing variable instead of declaring a new one

### Example

```jass
function MyFunction takes nothing returns nothing
    local integer counter = 0
    local integer counter = 10
    //            ^^^^^^^ JASS0128: Local variable 'counter' is already declared in this function
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer counter = 0
    local integer maxCount = 10
endfunction
```

Parameter conflict example:

```jass
function MyFunction takes integer value returns nothing
    local integer value = 5
    //            ^^^^^ JASS0128: Local variable 'value' is already declared in this function
endfunction
```

Fixed code:

```jass
function MyFunction takes integer value returns nothing
    local integer localValue = 5
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Local variable names must be unique within a function.
