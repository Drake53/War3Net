## JASS2901: Constant Function Modifies Global

| Property       | Value                          |
|----------------|--------------------------------|
| **ID**         | JASS2901                       |
| **Descriptor** | ConstantFunctionModifiesGlobal |
| **Category**   | Semantic                       |
| **Severity**   | Error                          |

### Cause

A constant function modifies a global variable.

### Rule description

Constant functions cannot modify global variables. Only local variables and parameters may be modified by set statements in a constant function.

### How to fix violations

1. Remove the `constant` modifier if the function needs to modify global state
2. Use a local variable instead of modifying a global variable

### Example

```jass
globals
    integer gValue = 0
endglobals

constant function Foo takes nothing returns integer
    set gValue = 5
//  ^^^^^^^^^^^^^^ JASS2901: Constant function cannot modify global variable 'gValue'
    return gValue
endfunction
```

Fixed code (use local variable):

```jass
constant function Foo takes nothing returns integer
    local integer x = 5
    return x
endfunction
```

Or remove constant modifier:

```jass
globals
    integer gValue = 0
endglobals

function Foo takes nothing returns integer
    set gValue = 5
    return gValue
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed.
