## JASS1039: Unterminated String

| Property       | Value              |
|----------------|--------------------|
| **ID**         | JASS1039           |
| **Descriptor** | UnterminatedString |
| **Category**   | Syntax             |
| **Severity**   | Error              |

### Cause

This diagnostic is triggered when a string literal is missing its closing double quote.

### Rule description

String literals in JASS must be enclosed in double quotes (`"`). A string that begins with a double quote must end with a double quote. If the closing quote is missing, the parser cannot determine where the string ends.

### How to fix violations

1. Add the missing closing double quote at the end of the string
2. If the string contains a quote character, escape it as `\"`

### Example

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("Hello World)
    //              ^^^^^^^^^^^^^ JASS1039: Unterminated string literal
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("Hello World")
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The string literal must be properly terminated.
