## JASS1003: Syntax Error

| Property       | Value       |
|----------------|-------------|
| **ID**         | JASS1003    |
| **Descriptor** | SyntaxError |
| **Category**   | Syntax      |
| **Severity**   | Error       |

### Cause

This diagnostic is triggered when the parser expects a specific symbol, keyword, or syntactic element but encounters something else instead.

### Rule description

JASS has a strict grammar that requires specific tokens at specific positions. When a required token is missing or a different token appears in its place, this error is reported with a message indicating what was expected. Common cases include:

- Missing comma between function arguments
- Missing parentheses in function calls or expressions
- Missing keywords like `returns` in function declarations
- Unexpected tokens at declaration or statement boundaries

The message format is `Syntax error, {0} expected`, where `{0}` is replaced with the expected token or description.

### How to fix violations

1. Add the missing token indicated in the error message
2. Check for misplaced or extra tokens that disrupt the expected syntax
3. Verify the overall structure of the declaration or statement

### Example

```jass
function Add takes integer a integer b returns integer
//                           ^^^^^^^ JASS1003: Syntax error, ',' expected
    return a + b
endfunction
```

Fixed code:

```jass
function Add takes integer a, integer b returns integer
    return a + b
endfunction
```

Another example:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("hello"
    // JASS1003: Syntax error, ')' expected
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("hello")
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The syntax must be corrected to match the expected grammar.
