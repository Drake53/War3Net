## JASS1733: Missing Expression At End

| Property       | Value                  |
|----------------|------------------------|
| **ID**         | JASS1733               |
| **Descriptor** | MissingExpressionAtEnd |
| **Category**   | Syntax                 |
| **Severity**   | Error                  |

### Cause

This diagnostic is triggered when an expression is expected but the end of input is reached, so there is no token to begin the expression.

### Rule description

Many JASS constructs require an expression, such as the right-hand side of an assignment, a function argument, or the operand of an operator. When an expression is required but the input ends before one begins, this error is reported.

### How to fix violations

Complete the expression, or remove the trailing operator that requires one.

### Example

```jass
function MyFunction takes nothing returns nothing
    set x = 5 +
    //        ^ JASS1733: Expression expected
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    set x = 5 + 1
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. An expression must be provided.
