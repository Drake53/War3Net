## JASS2927: Inconsistent Indentation

| Property       | Value                   |
|----------------|-------------------------|
| **ID**         | JASS2927                |
| **Descriptor** | InconsistentIndentation |
| **Category**   | Style                   |
| **Severity**   | Warning                 |

### Cause

This diagnostic is triggered when indentation does not match the expected indentation style. The expected indentation string is determined from analyzer config options (e.g., `.editorconfig`), defaulting to 4 spaces.

### Rule description

Each line's indentation must consist of zero or more exact repetitions of the expected indentation string. This covers:
- Wrong indentation width (e.g., 2 spaces when 4 are expected)
- Mixed tabs and spaces (e.g., tabs when spaces are expected)
- Partial indentation (e.g., 6 spaces when the unit is 4)

### Configuration

The expected indentation is resolved from `JassAnalyzerConfigOptionsProvider` using standard `.editorconfig` keys:

| Key | Values | Default |
|-----|--------|---------|
| `indent_style` | `space`, `tab` | `space` |
| `indent_size` | Any positive integer | `4` |

When no provider is configured, the default is 4 spaces.

### How to fix violations

1. Configure your editor to use consistent indentation matching the project settings
2. Apply consistent indentation throughout the file
3. Use a code formatter if available

### Example

Using default settings (4 spaces):

```jass
function MyFunction takes integer x returns nothing
  call DoSomething()    // Wrong - 2 spaces instead of 4
	set x = x - 1        // Wrong - tab instead of spaces
endfunction
// JASS2927: Inconsistent indentation; expected '4 spaces' but found '2 spaces'
// JASS2927: Inconsistent indentation; expected '4 spaces' but found 'tab'
```

Fixed code:

```jass
function MyFunction takes integer x returns nothing
    call DoSomething()
    set x = x - 1
endfunction
```

### When to suppress warnings

Suppress this warning when:
- Working with legacy code that can't be reformatted
- Automated formatting will be applied later
