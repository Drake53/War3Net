## JASS1525: Missing Expression

| Property       | Value             |
|----------------|-------------------|
| **ID**         | JASS1525          |
| **Descriptor** | MissingExpression |
| **Category**   | Syntax            |
| **Severity**   | Error             |

### Cause

This diagnostic is triggered when an expression is expected but an invalid term is found. This typically occurs in contexts like assignments, function arguments, return statements, or conditions.

### Rule description

Many JASS constructs require expressions:
- Variable assignments: `set x = expression`
- Function arguments: `call Func(expression)`
- Return statements: `return expression`
- Conditions: `if expression then`
- Array indexing: `array[expression]`

When the parser expects an expression but finds something else (or nothing), this error is raised.

### How to fix violations

Add the missing expression in the appropriate location.

### Example

```jass
function MyFunction takes nothing returns nothing
    set x =
    //     ^ JASS1525: Invalid expression term '{term}'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    set x = 5
endfunction
```

Function argument example:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething(, 5)
    //               ^ JASS1525: Invalid expression term '{term}'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething(10, 5)
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. An expression must be provided.
