## JASS0029: Type Mismatch

| Property       | Value        |
|----------------|--------------|
| **ID**         | JASS0029     |
| **Descriptor** | TypeMismatch |
| **Category**   | Semantic     |
| **Severity**   | Error        |

### Cause

This diagnostic is triggered when an expression's type does not match the expected type. This covers assignments, return statements, conditions, and array indices.

### Rule description

JASS is a statically typed language. The type of an expression must be compatible with the type expected by its context:

- **Assignments and initializations**: the expression type must be compatible with the variable's declared type.
- **Return statements**: the expression type must be compatible with the function's declared return type.
- **Conditions** (`if`, `elseif`, `exitwhen`): the expression must be of type `boolean`.
- **Array indices**: the expression must be of type `integer`.

Compatible conversions:
- Same types (e.g., `integer` to `integer`)
- `integer` to `real`
- Handle subtypes to parent types (e.g., `unit` to `handle`)
- `null` to handle/string types

### How to fix violations

1. Change the expression to produce the correct type
2. Change the variable's or function's declared type
3. Use a conversion function if available (e.g., `R2I`, `I2S`, `S2I`)

### Example

```jass
function MyFunction takes nothing returns nothing
    local integer x = "hello"
    //                ^^^^^^^ JASS0029: Cannot implicitly convert type 'string' to 'integer'
endfunction
```

```jass
function GetValue takes nothing returns integer
    return "hello"
    //     ^^^^^^^ JASS0029: Cannot implicitly convert type 'string' to 'integer'
endfunction
```

```jass
function MyFunction takes nothing returns nothing
    if 5 then
    // ^ JASS0029: Cannot implicitly convert type 'integer' to 'boolean'
    endif
endfunction
```

```jass
function MyFunction takes nothing returns nothing
    local integer array arr
    local integer x = arr["hello"]
    //                    ^^^^^^^ JASS0029: Cannot implicitly convert type 'string' to 'integer'
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Types must be compatible.
