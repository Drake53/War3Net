## JASS0028: Entry Point Has Wrong Signature

| Property       | Value                    |
|----------------|--------------------------|
| **ID**         | JASS0028                 |
| **Descriptor** | EntryPointWrongSignature |
| **Category**   | Semantic                 |
| **Severity**   | Error                    |

### Cause

The entry point function `main` or `config` in a map script (`war3map.j`) is declared with parameters or a non-`nothing` return type.

### Rule description

The Warcraft III engine calls `main` and `config` with no arguments and does not handle any return value. Both must be declared with the exact signature `takes nothing returns nothing`.

This diagnostic is **only** reported when the source file is named `war3map.j`.

### How to fix violations

Change the entry point's signature to `takes nothing returns nothing`.

### Example

```jass
// war3map.j
function main takes integer difficulty returns nothing
//       ^^^^ JASS0028: Entry point function 'main' must take nothing and return nothing
endfunction
```

Fixed code:

```jass
// war3map.j
function main takes nothing returns nothing
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The game engine calls these functions with a fixed signature.
