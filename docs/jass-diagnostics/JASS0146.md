## JASS0146: Circular Type Extension

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS0146              |
| **Descriptor** | CircularTypeExtension |
| **Category**   | Semantic              |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when a type extension chain forms a cycle, meaning a type directly or indirectly extends itself.

### Rule description

In JASS, types declared with `type ... extends ...` must form an acyclic hierarchy rooted at `handle`. A circular dependency occurs when:
- A type extends itself directly
- Two or more types form a cycle (e.g., `A` extends `B` and `B` extends `A`)

### How to fix violations

1. Break the cycle by changing one of the type extensions to extend `handle` or another non-cyclic type
2. Remove the duplicate type declaration that introduces the cycle

### Example

Direct self-reference:

```jass
type mytype extends mytype
//                  ^^^^^^ JASS0146: Circular base type dependency involving 'mytype' and 'mytype'
```

Fixed code:

```jass
type mytype extends handle
```

Two-type cycle:

```jass
type typeA extends handle
type typeB extends typeA
type typeA extends typeB
//                 ^^^^^ JASS0146: Circular base type dependency involving 'typeA' and 'typeB'
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Type hierarchies must be acyclic.
