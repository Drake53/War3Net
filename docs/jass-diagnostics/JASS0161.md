## JASS0161: Missing Return

| Property       | Value         |
|----------------|---------------|
| **ID**         | JASS0161      |
| **Descriptor** | MissingReturn |
| **Category**   | Semantic      |
| **Severity**   | Error         |

### Cause

This diagnostic is triggered when a function that returns a value doesn't have a return statement on all code paths.

### Rule description

In JASS, functions that declare a return type other than `nothing` must return a value. The compiler performs control flow analysis to ensure:
- Every possible execution path ends with a `return` statement
- All branches of `if` statements have return statements if needed
- Loops don't prevent the return from being reached

### How to fix violations

1. Add return statements to all code paths
2. Add a default return at the end of the function
3. Ensure all branches of if-else statements return a value

### Example

```jass
function GetValue takes integer x returns integer
    if x > 0 then
        return x
    endif
    // JASS0161: Not all code paths return a value in function 'GetValue'
endfunction
```

Fixed code:

```jass
function GetValue takes integer x returns integer
    if x > 0 then
        return x
    endif
    return 0  // Default return
endfunction
```

Or with complete branching:

```jass
function GetValue takes integer x returns integer
    if x > 0 then
        return x
    else
        return 0
    endif
endfunction
```

Multiple branches:

```jass
function Classify takes integer x returns string
    if x < 0 then
        return "negative"
    elseif x > 0 then
        return "positive"
    endif
    // JASS0161: Not all code paths return a value in function 'Classify'
endfunction
```

Fixed code:

```jass
function Classify takes integer x returns string
    if x < 0 then
        return "negative"
    elseif x > 0 then
        return "positive"
    else
        return "zero"
    endif
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. All code paths must return a value in non-void functions.
