## JASS0123: Code Reference Must Take Nothing

| Property       | Value                        |
|----------------|------------------------------|
| **ID**         | JASS0123                     |
| **Descriptor** | CodeReferenceMustTakeNothing |
| **Category**   | Semantic                     |
| **Severity**   | Error                        |

### Cause

This diagnostic is triggered when a `function` expression references a function that takes parameters.

### Rule description

A `code` value created with the `function` keyword is invoked by the game engine without arguments (for example as a trigger action, condition, or timer callback). The referenced function must therefore take nothing — there is no way to supply arguments through a `code` value.

### How to fix violations

Change the referenced function to take nothing, passing data through globals instead, or reference a different function.

### Example

```jass
function Callback takes integer x returns nothing
endfunction

function MyFunction takes nothing returns nothing
    local code c = function Callback
    //                      ^^^^^^^^ JASS0123: Function 'Callback' used as 'code' must take nothing
endfunction
```

Fixed code:

```jass
globals
    integer CallbackData = 0
endglobals

function Callback takes nothing returns nothing
    local integer x = CallbackData
endfunction

function MyFunction takes nothing returns nothing
    local code c = function Callback
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Functions used as `code` must take nothing.
