## JASS1025: End-of-line Expected

| Property       | Value             |
|----------------|-------------------|
| **ID**         | JASS1025          |
| **Descriptor** | EndOfLineExpected |
| **Category**   | Syntax            |
| **Severity**   | Error             |

### Cause

This diagnostic is triggered when multiple constructs appear on the same line where an end-of-line was expected between them.

### Rule description

In JASS, each statement or declaration must start on its own line. Unlike languages that use semicolons or braces as delimiters, JASS uses newlines to separate constructs.

### How to fix violations

Place each statement or declaration on its own line.

### Example

```jass
function Foo takes nothing returns nothing
    call Foo() call Foo()
    //         ^^^^ JASS1025: End-of-line expected
endfunction
```

Fixed code:

```jass
function Foo takes nothing returns nothing
    call Foo()
    call Foo()
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Each construct must appear on its own line.
