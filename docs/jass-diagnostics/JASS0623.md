## JASS0623: Array Initializer Not Allowed

| Property       | Value                      |
|----------------|----------------------------|
| **ID**         | JASS0623                   |
| **Descriptor** | ArrayInitializerNotAllowed |
| **Category**   | Syntax                     |
| **Severity**   | Error                      |

### Cause

This diagnostic is triggered when an array declaration has an initializer.

### Rule description

JASS arrays cannot be initialized at their declaration. An array declaration only introduces the array variable; elements must be assigned individually with a `set` statement.

### How to fix violations

Remove the initializer and assign elements with `set` statements instead.

### Examples

Local array with initializer:

```jass
function MyFunction takes nothing returns nothing
    local integer array x = 5
    //                    ^^^ JASS0623: Array declarations cannot have an initializer
endfunction
```

Global array with initializer:

```jass
globals
    integer array x = 5
    //              ^^^ JASS0623: Array declarations cannot have an initializer
endglobals
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer array x
    set x[0] = 5
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Assign array elements individually with a `set` statement.
