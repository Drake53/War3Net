## JASS0020: Division By Zero

| Property       | Value          |
|----------------|----------------|
| **ID**         | JASS0020       |
| **Descriptor** | DivisionByZero |
| **Category**   | CodeQuality    |
| **Severity**   | Warning        |

### Cause

This diagnostic is triggered when a constant expression evaluating to zero is used as a divisor in a division expression.

### Rule description

Dividing by zero in JASS crashes the thread. When the divisor is a constant zero, the error can be detected statically. This typically indicates a logic error.

### How to fix violations

1. Replace the zero divisor with the intended value
2. Remove the division if it is unreachable or unnecessary

### Example

```jass
function Bad takes integer x returns integer
    return x / 0
    //         ^ JASS0020: Division by constant zero
endfunction
```

Fixed code:

```jass
function Bad takes integer x, integer divisor returns integer
    if divisor == 0 then
        return 0
    endif
    return x / divisor
endfunction
```

### When to suppress warnings

This warning should not be suppressed.
