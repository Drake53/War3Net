## JASS1011: Empty Single-Quoted Literal

| Property       | Value                    |
|----------------|--------------------------|
| **ID**         | JASS1011                 |
| **Descriptor** | EmptySingleQuotedLiteral |
| **Category**   | Syntax                   |
| **Severity**   | Error                    |

### Cause

This diagnostic is triggered when a single-quoted literal contains no characters (`''`).

### Rule description

A single-quoted literal must contain exactly 1 character (a character literal) or exactly 4 characters (a FourCC literal). An empty literal has no value to represent.

### How to fix violations

Provide a character or FourCC value inside the quotes.

### Example

```jass
globals
    integer x = ''
    //          ^^ JASS1011: Empty single-quoted literal
endglobals
```

Fixed code:

```jass
globals
    integer x = 'A'
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Single-quoted literals must contain exactly 1 or 4 characters.
