## JASS0110: Circular Constant Definition

| Property       | Value                      |
|----------------|----------------------------|
| **ID**         | JASS0110                   |
| **Descriptor** | CircularConstantDefinition |
| **Category**   | Semantic                   |
| **Severity**   | Error                      |

### Cause

This diagnostic is triggered when the initializer of a global constant references the constant being defined.

### Rule description

A constant's value must be computable without referring to itself.

### How to fix violations

Initialize the constant with a value that does not depend on the constant itself.

### Example

```jass
globals
    constant integer A = A + 1
    //                   ^ JASS0110: The evaluation of the constant value for 'A' involves a circular definition
endglobals
```

Fixed code:

```jass
globals
    constant integer A = 1
    constant integer B = A + 1
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. A constant cannot be defined in terms of itself.
