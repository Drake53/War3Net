## JASS1519: Invalid Statement Location

| Property       | Value                    |
|----------------|--------------------------|
| **ID**         | JASS1519                 |
| **Descriptor** | InvalidStatementLocation |
| **Category**   | Syntax                   |
| **Severity**   | Error                    |

### Cause

This diagnostic is triggered when a statement appears in a location where it is not allowed according to JASS syntax rules.

### Rule description

In JASS, statements can only appear in specific contexts:
- Inside function bodies (between `function` and `endfunction`)
- Inside control flow blocks (`if`...`endif`, `loop`...`endloop`)

Statements cannot appear:
- At the top level of the file (outside functions)
- Inside `globals` blocks (only declarations allowed)

### How to fix violations

Move the statement inside a function body where it can be executed.

### Example

```jass
globals
    integer x = 5
endglobals

call DoSomething()
// ^^^^^^^^^^^^^^^ JASS1519: Statement not allowed at this location

function MyFunction takes nothing returns nothing
endfunction
```

Fixed code:

```jass
globals
    integer x = 5
endglobals

function MyFunction takes nothing returns nothing
    call DoSomething()
endfunction
```

Statement in globals block:

```jass
globals
    integer x = 5
    set x = 10
    // ^^^^^^^ JASS1519: Statement not allowed at this location
endglobals
```

Fixed code:

```jass
globals
    integer x = 10  // Initialize directly
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Statements must appear in valid locations.
