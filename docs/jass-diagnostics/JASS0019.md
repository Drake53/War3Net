## JASS0019: Incompatible Operand Types

| Property       | Value                    |
|----------------|--------------------------|
| **ID**         | JASS0019                 |
| **Descriptor** | IncompatibleOperandTypes |
| **Category**   | Semantic                 |
| **Severity**   | Error                    |

### Cause

This diagnostic is triggered when a binary operator is used with operands of incompatible types.

### Rule description

Binary operators in JASS have specific type requirements:

**Arithmetic operators (`+`, `-`, `*`, `/`):**
- Both operands must be `integer` or `real`
- String concatenation uses `+` with both operands as `string`

**Equality operators (`==`, `!=`):**
- Numeric comparisons: both `integer` or `real`
- String comparisons: both `string`
- Handle comparisons: compatible handle types or `null`

**Ordered comparison operators (`<`, `<=`, `>`, `>=`):**
- Both operands must be `integer` or `real`

**Logical operators (`and`, `or`):**
- Both operands must be `boolean`

### How to fix violations

1. Convert one or both operands to compatible types
2. Use the correct operator for the types involved
3. Change the operand expressions to produce compatible types

### Example

```jass
function MyFunction takes nothing returns nothing
    local integer result = 5 + "hello"
    //                     ^^^^^^^^^^^ JASS0019: Operator '+' cannot be applied to operands of type 'integer' and 'string'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local string result = I2S(5) + "hello"  // "5hello"
endfunction
```

Logical operator example:

```jass
function MyFunction takes nothing returns nothing
    if 5 and 10 then
    // ^^^^^^^^ JASS0019: Operator 'and' cannot be applied to operands of type 'integer' and 'integer'
    endif
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    if (5 > 0) and (10 > 0) then
    endif
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Operator operands must have compatible types.
