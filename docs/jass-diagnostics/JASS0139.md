## JASS0139: ExitWhen Outside Loop

| Property       | Value               |
|----------------|---------------------|
| **ID**         | JASS0139            |
| **Descriptor** | ExitWhenOutsideLoop |
| **Category**   | Semantic            |
| **Severity**   | Error               |

### Cause

This diagnostic is triggered when an `exitwhen` statement appears outside of a loop.

### Rule description

In JASS, the `exitwhen` statement is used to conditionally exit from a `loop`. It can only appear inside a loop body. The `exitwhen` exits the innermost enclosing loop when its condition is true.

```jass
loop
    exitwhen condition  // Valid - inside loop
endloop

exitwhen condition  // Invalid - outside loop
```

### How to fix violations

1. Move the `exitwhen` inside a loop
2. Use `return` instead if you want to exit a function
3. Restructure the code to use a loop if conditional iteration is needed

### Example

```jass
function MyFunction takes nothing returns nothing
    exitwhen true
    // JASS0139: 'exitwhen' must be inside a 'loop' statement
endfunction
```

Fixed code (use return for function exit):

```jass
function MyFunction takes nothing returns nothing
    if true then
        return
    endif
endfunction
```

Or use in a loop:

```jass
function MyFunction takes nothing returns nothing
    loop
        exitwhen true
    endloop
endfunction
```

In if statement outside loop:

```jass
function MyFunction takes nothing returns nothing
    if someCondition then
        exitwhen true
        // JASS0139: 'exitwhen' must be inside a 'loop' statement
    endif
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    loop
        exitwhen someCondition
    endloop
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. `exitwhen` can only appear inside loops.
