## JASS1040: Construct Must Appear On Own Line

| Property       | Value                        |
|----------------|------------------------------|
| **ID**         | JASS1040                     |
| **Descriptor** | ConstructMustAppearOnOwnLine |
| **Category**   | Syntax                       |
| **Severity**   | Error                        |

### Cause

This diagnostic is triggered when a construct is split across multiple lines where the parser expected it to continue on the same line.

### Rule description

In JASS, certain constructs must be written on a single line. When a newline appears in the middle of a statement or expression that the parser expects to be contiguous, this diagnostic is reported.

### How to fix violations

Ensure the entire construct appears on a single line without intervening newlines.

### Example

```jass
function Foo takes nothing returns nothing
    call
    Foo
//  ^^^ JASS1040: Construct must appear as the first token on a line
    (
    )
endfunction
```

Fixed code:

```jass
function Foo takes nothing returns nothing
    call Foo()
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Constructs must not be split across lines.
