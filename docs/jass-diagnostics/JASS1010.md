## JASS1010: Unterminated Single-Quoted Literal

| Property       | Value                           |
|----------------|---------------------------------|
| **ID**         | JASS1010                        |
| **Descriptor** | UnterminatedSingleQuotedLiteral |
| **Category**   | Syntax                          |
| **Severity**   | Error                           |

### Cause

This diagnostic is triggered when a single-quoted literal is missing its closing single quote.

### Rule description

Single-quoted literals in JASS are enclosed in single quotes (`'`). A literal that begins with a single quote must end with a single quote. Single-quoted literals are used for single characters and FourCC codes (4-character identifiers used for game object types).

### How to fix violations

1. Add the missing closing single quote
2. If the character is a single quote itself, escape it as `\'`
3. Ensure FourCC literals have exactly 4 characters followed by a closing quote

### Example

```jass
function Test takes nothing returns nothing
    local integer c = 'A
    //                ^^ JASS1010: Unterminated single-quoted literal
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    local integer c = 'A'
endfunction
```

FourCC example:

```jass
globals
    integer UNIT_TYPE = 'hfoo
    //                  ^^^^^ JASS1010: Unterminated single-quoted literal
endglobals
```

Fixed code:

```jass
globals
    integer UNIT_TYPE = 'hfoo'
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The single-quoted literal must be properly terminated.
