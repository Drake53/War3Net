## JCA2234: Unsupported Audio Format

| Property       | Value                  |
|----------------|------------------------|
| **ID**         | JCA2234                |
| **Descriptor** | UnsupportedAudioFormat |
| **Category**   | Compatibility          |
| **Severity**   | Warning                |

### Cause

This diagnostic is triggered when an audio file path argument to a sound or music function uses a file extension that is not in the set of supported audio formats.

### Rule description

Warcraft III supports a limited set of audio file formats. Passing an unsupported format to a sound or music native will silently fail at runtime. This diagnostic detects unsupported extensions when either the full file path or the file's extension can be evaluated at compile-time.

The set of supported extensions is configurable. By default, `.mp3` and `.wav` are considered supported.

### Affected functions

`CreateSound`, `CreateSoundFilenameWithLabel`, `CreateMIDISound`, `PlayMusic`, `PlayMusicEx`, `PlayThematicMusic`, `PlayThematicMusicEx`, `SetMapMusic`, `GetSoundFileDuration`, `PlaySound`, `PlayMusicBJ`, `PlayMusicExBJ`, `PlayThematicMusicBJ`, `PlayThematicMusicExBJ`

### Configuration

The supported audio extensions can be configured via `.editorconfig` or `.globalconfig`:

```ini
jass_diagnostic.JASS3076.supported_audio_extensions = .mp3, .wav, .flac
```

The value is a comma-separated list of file extensions (with leading dot). The default when not configured is `.mp3, .wav`.

### How to fix violations

1. Convert the audio file to a supported format (e.g. `.mp3` or `.wav`)
2. If the format is supported by the game version you're targeting, add it to the supported extensions in your `.editorconfig`

### Example

```jass
function Start takes nothing returns nothing
    call PlayMusic("war3mapImported\\BGM.flac")
    //             ^^^^^^^^^^^^^^^^^^^^^^^^^^^ JASS3076: Audio file argument may use unsupported format '.flac'
endfunction
```

Dynamic concatenation is also detected:

```jass
function Start takes integer i returns nothing
    call PlayMusic("BGM" + I2S(i) + ".flac")
    //             ^^^^^^^^^^^^^^^^^^^^^^^^ JASS3076: Audio file argument may use unsupported format '.flac'
endfunction
```

Fixed code:

```jass
function Start takes nothing returns nothing
    call PlayMusic("war3mapImported\\BGM.mp3")
endfunction
```

### When to suppress warnings

This warning should not be suppressed. If this diagnostic triggers unexpectedly, you should update your `.editorconfig` instead.
