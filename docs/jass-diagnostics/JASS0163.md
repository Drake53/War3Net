## JASS0163: Unreachable Code After Return

| Property       | Value                      |
|----------------|----------------------------|
| **ID**         | JASS0163                   |
| **Descriptor** | UnreachableCodeAfterReturn |
| **Category**   | Semantic                   |
| **Severity**   | Error                      |

### Cause

This diagnostic is triggered when code appears after a root-level return statement in a function body. A root-level return is a return statement that is not nested inside an `if` or `loop` block.

### Rule description

In JASS, a return statement at the top level of a function body always causes the function to exit. Any statements after it can never execute.

This diagnostic only applies to return statements at the function's root scope. Return statements inside `if` or `loop` blocks trigger JASS0162 instead. The scope of this diagnostic is intentionally limited to match the official JASS implementation.

### How to fix violations

1. Remove the unreachable code
2. Move the code before the return statement
3. Restructure the control flow if the code is needed

### Example

```jass
function MyFunction takes nothing returns integer
    return 5
    local integer x = 10
    // JASS0163: Unreachable code detected
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns integer
    return 5
endfunction
```

### When to suppress warnings

This diagnostic can be suppressed if you wish to make use of the return bug which was present in older game versions (before 1.24).
