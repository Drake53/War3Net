## JASS1513: Missing Closing Keyword

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS1513              |
| **Descriptor** | MissingClosingKeyword |
| **Category**   | Syntax                |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when a block is missing its closing keyword (`endfunction`, `endglobals`, `endif`, or `endloop`).

### Rule description

In JASS, every block construct must be terminated with its corresponding closing keyword:

```jass
function FunctionName takes nothing returns nothing
    // statements
endfunction

globals
    // global variable declarations
endglobals

if condition then
    // statements
endif

loop
    // statements
endloop
```

### How to fix violations

Add the missing closing keyword at the end of the block.

### Examples

Missing `endfunction`:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething()
// JASS1513: 'endfunction' expected

function AnotherFunction takes nothing returns nothing
    call DoOther()
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething()
endfunction

function AnotherFunction takes nothing returns nothing
    call DoOther()
endfunction
```

Missing `endif`:

```jass
function MyFunction takes nothing returns nothing
    if x > 5 then
        call DoSomething()
    // JASS1513: 'endif' expected
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    if x > 5 then
        call DoSomething()
    endif
endfunction
```

Globals block inside a function body (missing `endfunction`):

```jass
function foo takes nothing returns nothing
    call Bar()
globals
// ^^^^^^^ JASS1513: 'endfunction' expected
    integer x = 5
endglobals
```

Fixed code:

```jass
globals
    integer x = 5
endglobals

function foo takes nothing returns nothing
    call Bar()
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Every block must have its matching closing keyword.
