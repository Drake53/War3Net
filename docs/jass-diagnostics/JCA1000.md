## JCA1000: Constant Function Returns Nothing

| Property       | Value                          |
|----------------|--------------------------------|
| **ID**         | JCA1000                        |
| **Descriptor** | ConstantFunctionReturnsNothing |
| **Category**   | CodeQuality                    |
| **Severity**   | Warning                        |

### Cause

A function declared `constant` has a return type of `nothing`.

### Rule description

A `constant` function is essentially a pure function, meaning it can only compute values without side effects. A constant function that returns `nothing` produces no value and can have no useful effect. This almost always indicates a mistake: either the `constant` modifier is spurious, or the function should return a value.

### How to fix violations

1. Remove the `constant` modifier if the function is meant to have side effects
2. Give the function a meaningful return type if it is meant to compute a value

### Example

```jass
constant function GetValue takes nothing returns nothing
//                ^^^^^^^^ JCA1000: Constant function should not return nothing
endfunction
```

Fixed code (return a value):

```jass
constant function GetValue takes nothing returns integer
    return 42
endfunction
```

Or remove the constant modifier:

```jass
function DoWork takes nothing returns nothing
endfunction
```

### When to suppress warnings

This warning should not be suppressed. A `constant` function should always return a value.
