## JASS1503: Argument Type Mismatch

| Property       | Value                |
|----------------|----------------------|
| **ID**         | JASS1503             |
| **Descriptor** | ArgumentTypeMismatch |
| **Category**   | Semantic             |
| **Severity**   | Error                |

### Cause

This diagnostic is triggered when a function invocation's argument's type doesn't match the expected parameter type.

### Rule description

When calling a function, each argument must be either the same as or implicitly convertable to the corresponding parameter's declared type.

### How to fix violations

1. Change the argument expression to produce the correct type
2. Use a conversion function (e.g., `I2S`, `R2I`, `S2I`)
3. Verify you're calling the correct function with correct argument order

### Example

```jass
native DisplayTextToPlayer takes player p, real x, real y, string msg returns nothing

function MyFunction takes nothing returns nothing
    call DisplayTextToPlayer(Player(0), 0, 0, 42)
    //                                        ^^ JASS1503: Argument 4: cannot convert from 'integer' to 'string'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call DisplayTextToPlayer(Player(0), 0, 0, I2S(42))
endfunction
```

Or with a string literal:

```jass
function MyFunction takes nothing returns nothing
    call DisplayTextToPlayer(Player(0), 0, 0, "42")
endfunction
```

Wrong argument order:

```jass
function Calculate takes integer a, string b returns nothing
endfunction

function MyFunction takes nothing returns nothing
    call Calculate("hello", 5)
    //             ^^^^^^^ JASS1503: Argument 1: cannot convert from 'string' to 'integer'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call Calculate(5, "hello")
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Function arguments must match parameter types.
