## JASS0023: Invalid Unary Operand

| Property       | Value               |
|----------------|---------------------|
| **ID**         | JASS0023            |
| **Descriptor** | InvalidUnaryOperand |
| **Category**   | Semantic            |
| **Severity**   | Error               |

### Cause

This diagnostic is triggered when a unary operator is applied to an operand of an incompatible type.

### Rule description

JASS has three unary operators with specific type requirements:

**Unary plus (`+`):**
- Operand must be `integer` or `real`

**Unary minus (`-`):**
- Operand must be `integer` or `real`

**Logical not (`not`):**
- Operand must be `boolean`

### How to fix violations

1. Change the operand expression to produce the correct type
2. Use a conversion function if needed
3. Use a different operator appropriate for the type

### Example

```jass
function MyFunction takes nothing returns nothing
    local integer x = -"hello"
    //                ^^^^^^^^ JASS0023: Operator '-' cannot be applied to operand of type 'string'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer x = -5
endfunction
```

Logical not example:

```jass
function MyFunction takes nothing returns nothing
    local boolean b = not 5
    //                ^^^^^ JASS0023: Operator 'not' cannot be applied to operand of type 'integer'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local boolean b = not (5 > 0)
endfunction
```

Or:

```jass
function MyFunction takes nothing returns nothing
    local boolean b = (5 == 0)  // Check if equal to zero
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The operand must have a compatible type for the unary operator.
