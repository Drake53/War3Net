## JASS1501: Wrong Argument Count

| Property       | Value              |
|----------------|--------------------|
| **ID**         | JASS1501           |
| **Descriptor** | WrongArgumentCount |
| **Category**   | Semantic           |
| **Severity**   | Error              |

### Cause

This diagnostic is triggered when a function is called with a different number of arguments than it expects.

### Rule description

In JASS, functions have a fixed number of parameters. When calling a function:
- You must provide exactly the number of arguments the function expects
- JASS does not support optional parameters or variadic functions
- Functions declared with `takes nothing` must be called with no arguments

### How to fix violations

1. Add missing arguments
2. Remove extra arguments
3. Verify you're calling the correct function
4. Check the function declaration for the expected parameters

### Example

```jass
function AddNumbers takes integer a, integer b returns integer
    return a + b
endfunction

function MyFunction takes nothing returns nothing
    local integer result = AddNumbers(5)
    //                     ^^^^^^^^^^^^^ JASS1501: Function 'AddNumbers' expects 2 argument(s), but 1 were provided
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer result = AddNumbers(5, 10)
endfunction
```

Too many arguments:

```jass
function Greet takes string name returns nothing
    call BJDebugMsg("Hello, " + name)
endfunction

function MyFunction takes nothing returns nothing
    call Greet("World", "!")
    //   ^^^^^^^^^^^^^^^^^^^ JASS1501: Function 'Greet' expects 1 argument(s), but 2 were provided
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call Greet("World")
endfunction
```

No arguments expected:

```jass
function DoWork takes nothing returns nothing
endfunction

function MyFunction takes nothing returns nothing
    call DoWork(5)
    //   ^^^^^^^^^ JASS1501: Function 'DoWork' expects 0 argument(s), but 1 were provided
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call DoWork()
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Function calls must provide the correct number of arguments.
