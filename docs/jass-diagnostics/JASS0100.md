## JASS0100: Duplicate Parameter Name

| Property       | Value                  |
|----------------|------------------------|
| **ID**         | JASS0100               |
| **Descriptor** | DuplicateParameterName |
| **Category**   | Semantic               |
| **Severity**   | Error                  |

### Cause

This diagnostic is triggered when a function has multiple parameters with the same name.

### Rule description

In JASS, each parameter in a function's parameter list must have a unique name.

### How to fix violations

1. Rename one of the duplicate parameters to have a unique name
2. Remove the duplicate parameter if it's not needed

### Example

```jass
function MyFunction takes integer value, string value returns nothing
//                                              ^^^^^ JASS0100: Parameter 'value' is already defined
endfunction
```

Fixed code:

```jass
function MyFunction takes integer intValue, string strValue returns nothing
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Parameter names must be unique within a function.
