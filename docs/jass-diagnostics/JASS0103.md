## JASS0103: Undefined Name

| Property       | Value         |
|----------------|---------------|
| **ID**         | JASS0103      |
| **Descriptor** | UndefinedName |
| **Category**   | Semantic      |
| **Severity**   | Error         |

### Cause

This diagnostic is triggered when code references a name (variable or function) that has not been declared.

### Rule description

In JASS, all names must be declared before they can be used:
- Global variables must be declared in a `globals` block
- Local variables must be declared at the beginning of a function with the `local` keyword
- Function parameters are automatically in scope within the function
- User functions are declared with the `function` keyword
- Native functions are declared with the `native` keyword

The compiler checks that every name reference corresponds to a declared symbol.

### How to fix violations

1. Declare the variable or function before using it
2. Check for typos in the name
3. Verify the name is in scope (global vs local)
4. For functions, ensure the declaration appears before the call (JASS requires forward declaration)

### Example

Undefined variable:

```jass
function MyFunction takes nothing returns nothing
    set x = 5
    //  ^ JASS0103: The name 'x' does not exist in the current context
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer x
    set x = 5
endfunction
```

Undefined function:

```jass
function MyFunction takes nothing returns nothing
    call DoSomethingSpecial()
    //   ^^^^^^^^^^^^^^^^^^^^ JASS0103: The name 'DoSomethingSpecial' does not exist in the current context
endfunction
```

Fixed code:

```jass
function DoSomethingSpecial takes nothing returns nothing
    // implementation
endfunction

function MyFunction takes nothing returns nothing
    call DoSomethingSpecial()
endfunction
```

Typo example:

```jass
function MyFunction takes nothing returns nothing
    local integer counter = 0
    set cunter = cunter + 1
    //  ^^^^^^ JASS0103: The name 'cunter' does not exist in the current context
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer counter = 0
    set counter = counter + 1
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. All names must be declared.
