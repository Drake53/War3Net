## JASS0021: Array Access On Non-Array

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS0021              |
| **Descriptor** | ArrayAccessOnNonArray |
| **Category**   | Semantic              |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when array subscript notation `[index]` is used on a variable that is not declared as an array.

### Rule description

In JASS, only variables declared with the `array` keyword can use subscript access:

```jass
integer array myArray  // Array - can use myArray[0]
string myValue         // Not array - cannot use myValue[0]
```

The subscript operator `[]` can only be applied to array variables.

### How to fix violations

1. Declare the variable as an array if array access is needed
2. Remove the subscript if single-value access is intended
3. Use the correct array variable name

### Example

```jass
function MyFunction takes nothing returns nothing
    local integer value = 5
    set value[0] = 10
    //  ^^^^^ JASS0021: 'value' is not an array
endfunction
```

Fixed code (use array):

```jass
function MyFunction takes nothing returns nothing
    local integer array values
    set values[0] = 10
endfunction
```

Or without array:

```jass
function MyFunction takes nothing returns nothing
    local integer value = 5
    set value = 10  // Direct assignment
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Only array variables can use subscript notation.
