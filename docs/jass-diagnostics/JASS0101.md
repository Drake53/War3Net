## JASS0101: Duplicate Declaration

| Property       | Value                |
|----------------|----------------------|
| **ID**         | JASS0101             |
| **Descriptor** | DuplicateDeclaration |
| **Category**   | Semantic             |
| **Severity**   | Error                |

### Cause

This diagnostic is triggered when a symbol (type, function, native, or global variable) is declared with the same name as an already existing declaration.

### Rule description

In JASS, all declarations share a single global namespace. Each name must be unique across types, functions, natives, and global variables.

### How to fix violations

1. Rename the duplicate declaration to have a unique name
2. Remove the duplicate declaration if it's unintentional

### Example

Duplicate global variable:

```jass
globals
    integer playerCount = 0
    integer playerCount = 8
    //      ^^^^^^^^^^^ JASS0101: 'playerCount' is already declared
endglobals
```

Duplicate type:

```jass
type mywidget extends handle
type mywidget extends handle
//   ^^^^^^^^ JASS0101: 'mywidget' is already declared
```

Duplicate function:

```jass
native DoWork takes nothing returns nothing

function DoWork takes integer x returns nothing
//       ^^^^^^ JASS0101: 'DoWork' is already declared
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Declaration names must be unique.
