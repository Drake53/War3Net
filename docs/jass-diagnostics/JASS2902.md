## JASS2902: Constant Function Calls Non-Constant

| Property       | Value                            |
|----------------|----------------------------------|
| **ID**         | JASS2902                         |
| **Descriptor** | ConstantFunctionCallsNonConstant |
| **Category**   | Semantic                         |
| **Severity**   | Error                            |

### Cause

This diagnostic is triggered when a `constant` function invokes a non-constant function, either in an expression or via a `call` statement.

### Rule description

In JASS, `constant` functions may only call other constant functions or natives.
This applies to both function calls in expressions (e.g., `return GetValue()`) and `call` statements (e.g., `call DoSomething()`).

### How to fix violations

1. Make the called function constant if possible
2. Remove the `constant` modifier from the calling function
3. Refactor to avoid calling non-constant functions

### Example

```jass
function GetMultiplier takes nothing returns integer
    return 2
endfunction

constant function CalculateValue takes integer x returns integer
    return x * GetMultiplier()
    //         ^^^^^^^^^^^^^ JASS2902: Constant function cannot call non-constant function 'GetMultiplier'
endfunction
```

Fixed code (make called function constant):

```jass
constant function GetMultiplier takes nothing returns integer
    return 2
endfunction

constant function CalculateValue takes integer x returns integer
    return x * GetMultiplier()
endfunction
```

Or remove constant modifier:

```jass
function GetMultiplier takes nothing returns integer
    return 2
endfunction

function CalculateValue takes integer x returns integer
    return x * GetMultiplier()
endfunction
```

Or inline the value:

```jass
constant function CalculateValue takes integer x returns integer
    return x * 2  // Inline the multiplier
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Constant functions can only call constant functions.
