## JASS1514: Missing Then

| Property       | Value       |
|----------------|-------------|
| **ID**         | JASS1514    |
| **Descriptor** | MissingThen |
| **Category**   | Syntax      |
| **Severity**   | Error       |

### Cause

This diagnostic is triggered when an `if` or `elseif` clause is missing the required `then` keyword after the condition.

### Rule description

In JASS, the `if` and `elseif` keywords must be followed by a boolean condition and the `then` keyword.

```jass
if condition then
    // statements
elseif otherCondition then
    // statements
endif
```

### How to fix violations

Add the missing `then` keyword after the condition expression.

### Example

```jass
function MyFunction takes nothing returns nothing
    if x > 5
    //      ^ JASS1514: Missing 'then' after condition
        call DoSomething()
    endif
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    if x > 5 then
        call DoSomething()
    endif
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The `then` keyword is required.
