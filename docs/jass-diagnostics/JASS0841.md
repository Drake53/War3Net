## JASS0841: Forward Reference

| Property       | Value            |
|----------------|------------------|
| **ID**         | JASS0841         |
| **Descriptor** | ForwardReference |
| **Category**   | Semantic         |
| **Severity**   | Error            |

### Cause

This diagnostic is triggered when a symbol (function, variable, or type) is referenced before it has been declared in the source file.

### Rule description

JASS requires that all symbols be declared before they are used. The compiler processes declarations in a single pass from top to bottom. Native functions and built-in types declared in `common.j` and `Blizzard.j` are always available because they are processed first.

### How to fix violations

1. Move the declaration of the referenced symbol above the point where it is first used
2. Reorganize function definitions so that callees appear before callers

### Example

```jass
function Caller takes nothing returns nothing
    call Callee()
    //   ^^^^^^ JASS0841: 'Callee' must be declared before it is used
endfunction

function Callee takes nothing returns nothing
endfunction
```

Fixed code:

```jass
function Callee takes nothing returns nothing
endfunction

function Caller takes nothing returns nothing
    call Callee()
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed.
