## JASS1022: Missing Declaration

| Property       | Value              |
|----------------|--------------------|
| **ID**         | JASS1022           |
| **Descriptor** | MissingDeclaration |
| **Category**   | Syntax             |
| **Severity**   | Error              |

### Cause

This diagnostic is triggered when a top-level declaration is expected but none is found.

### Rule description

A JASS top-level declaration must begin with one of the declaration keywords, such as `globals`, `native`, and `function`. When a declaration is expected but the input begins with none of them, this error is reported.

### How to fix violations

1. Begin the declaration with a valid top-level keyword
2. Remove the stray tokens if no declaration was intended

### Example

```jass
Test takes nothing returns nothing
// ^ JASS1022: Statement expected
    call BJDebugMsg(I2S(5 + 3))
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg(I2S(5 + 3))
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. A valid declaration must be provided.
