## JASS0131: Cannot Assign To Constant

| Property       | Value                  |
|----------------|------------------------|
| **ID**         | JASS0131               |
| **Descriptor** | CannotAssignToConstant |
| **Category**   | Semantic               |
| **Severity**   | Error                  |

### Cause

This diagnostic is triggered when code attempts to assign a new value to a constant variable.

### Rule description

In JASS, variables declared with the `constant` modifier cannot be reassigned after initialization. Constants must be initialized in their declaration and cannot be modified afterwards.

```jass
constant integer MAX_PLAYERS = 12  // Can only be set once
```

The `set` statement cannot be used on constant variables.

### How to fix violations

1. Remove the `constant` modifier if the variable needs to be mutable
2. Use the constant's current value instead of trying to modify it
3. Create a new non-constant variable if a changing value is needed

### Example

```jass
globals
    constant integer MAX_VALUE = 100
endglobals

function MyFunction takes nothing returns nothing
    set MAX_VALUE = 200
    //  ^^^^^^^^^ JASS0131: Cannot assign to constant 'MAX_VALUE'
endfunction
```

Fixed code (use a non-constant variable):

```jass
globals
    integer currentMaxValue = 100
endglobals

function MyFunction takes nothing returns nothing
    set currentMaxValue = 200
endfunction
```

Or keep the constant and use a different variable:

```jass
globals
    constant integer DEFAULT_MAX = 100
endglobals

function MyFunction takes nothing returns nothing
    local integer maxValue = DEFAULT_MAX
    set maxValue = 200  // Local variable can be modified
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Constants cannot be reassigned.
