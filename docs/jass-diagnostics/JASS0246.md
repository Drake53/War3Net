## JASS0246: Undefined Type

| Property       | Value         |
|----------------|---------------|
| **ID**         | JASS0246      |
| **Descriptor** | UndefinedType |
| **Category**   | Semantic      |
| **Severity**   | Error         |

### Cause

This diagnostic is triggered when code references a type that has not been declared, including base types in type declarations.

### Rule description

JASS has built-in primitive types and allows custom types:

**Built-in types:**
- `integer`
- `real` (floating-point number)
- `boolean`
- `string`
- `handle` (object)
- `code` (function pointer)
- `nothing` (void)

**Custom types:**
- Declared with `type CustomType extends BaseType`
- Must extend from `handle` or another handle-derived type

The compiler verifies that all type references are valid.

### How to fix violations

1. Use a built-in type if appropriate
2. Declare the custom type before using it
3. Check for typos in the type name
4. Verify the type is declared in `common.j` or your script

### Example

```jass
function MyFunction takes nothing returns nothing
    local myunit u = null
    //    ^^^^^^ JASS0246: Undefined type 'myunit'
endfunction
```

Fixed code:

```jass
type myunit extends handle

function MyFunction takes nothing returns nothing
    local myunit u = null
endfunction
```

Or using a built-in type:

```jass
function MyFunction takes nothing returns nothing
    local unit u = null
endfunction
```

Typo example:

```jass
function MyFunction takes nothing returns nothing
    local integr x = 5
    //    ^^^^^^ JASS0246: Undefined type 'integr'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer x = 5
endfunction
```

Type declaration with undefined base type:

```jass
type mytype extends nonexistent
//                  ^^^^^^^^^^^ JASS0246: Undefined type 'nonexistent'
```

Fixed code:

```jass
type mytype extends handle
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. All types must be defined.
