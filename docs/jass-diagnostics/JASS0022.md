## JASS0022: Missing Array Subscript

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS0022              |
| **Descriptor** | MissingArraySubscript |
| **Category**   | Semantic              |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when an array variable is used without a subscript to access a specific element.

### Rule description

In JASS, array variables must be accessed with an index when reading or writing values:

```jass
myArray[0] = 5   // Correct - writing to element
x = myArray[0]   // Correct - reading element
x = myArray      // Error - missing subscript
```

Arrays cannot be used as a whole; individual elements must be accessed.

### How to fix violations

1. Add a subscript to access a specific element
2. Use a non-array variable if whole-value semantics are needed
3. Loop through elements if you need to process the entire array

### Example

```jass
globals
    integer array values
endglobals

function MyFunction takes nothing returns nothing
    local integer array x = values
    //                      ^^^^^^ JASS0022: Array 'values' must be accessed with subscript
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local integer x = values[0]  // Access specific element
endfunction
```

Assignment example:

```jass
function CopyArray takes nothing returns nothing
    local integer array source
    local integer array dest
    set dest = source
    //  ^^^^ JASS0022: Array 'dest' must be accessed with subscript
endfunction
```

Fixed code:

```jass
function CopyArray takes nothing returns nothing
    local integer array source
    local integer array dest
    local integer i = 0
    loop
        exitwhen i >= 10
        set dest[i] = source[i]  // Copy element by element
        set i = i + 1
    endloop
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Array elements must be accessed individually.
