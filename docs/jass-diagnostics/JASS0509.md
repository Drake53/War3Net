## JASS0509: Cannot Extend Primitive Type

| Property       | Value                     |
|----------------|---------------------------|
| **ID**         | JASS0509                  |
| **Descriptor** | CannotExtendPrimitiveType |
| **Category**   | Semantic                  |
| **Severity**   | Error                     |

### Cause

This diagnostic is triggered when a type declaration attempts to extend a primitive type.

### Rule description

In JASS, custom types can only extend from:
- The `handle` base type
- Other types that themselves derive from `handle`

Primitive types cannot be extended: `integer`, `real`, `boolean`, `string`, `code`.

For `nothing`, see [JASS1547](JASS1547.md).

### How to fix violations

1. Extend from `handle` instead of a primitive type
2. Extend from an existing handle-derived type

### Example

```jass
type myint extends integer
//                 ^^^^^^^ JASS0509: 'myint' cannot extend primitive type 'integer'
```

Fixed code:

```jass
type myint extends handle
```

Another example:

```jass
type mystr extends string
//                 ^^^^^^ JASS0509: 'mystr' cannot extend primitive type 'string'
```

Fixed code:

```jass
type mystr extends handle
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Types can only extend from `handle` or handle-derived types.
