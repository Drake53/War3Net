## JASS8803: Declaration Order Violation

| Property       | Value                     |
|----------------|---------------------------|
| **ID**         | JASS8803                  |
| **Descriptor** | DeclarationOrderViolation |
| **Category**   | Semantic                  |
| **Severity**   | Error                     |

### Cause

This diagnostic is triggered when a top-level declaration appears after a declaration kind that must come later in the file.

### Rule description

JASS requires top-level declarations to follow a strict order:

1. `type` declarations
2. `globals` block
3. `native` declarations
4. `function` declarations

A declaration of an earlier kind may not appear after a later kind. For example, a `type` declaration may not follow a `globals` block, and a `native` declaration may not follow a `function` declaration.

### How to fix violations

Reorder the declarations so that all type declarations come first, followed by the globals block, then native declarations, and finally function declarations.

### Example

```jass
function Foo takes nothing returns nothing
endfunction

native Bar takes nothing returns nothing
// ^^^^^^ JASS8803: A native declaration may not follow a function declaration
```

Fixed code:

```jass
native Bar takes nothing returns nothing

function Foo takes nothing returns nothing
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed.
