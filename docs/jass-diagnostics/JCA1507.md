## JCA1507: ExecuteFunc On Nonexistent

| Property       | Value                    |
|----------------|--------------------------|
| **ID**         | JCA1507                  |
| **Descriptor** | ExecuteFuncOnNonexistent |
| **Category**   | Compatibility            |
| **Severity**   | Warning                  |

### Cause

This diagnostic is triggered when `ExecuteFunc` is called with a string argument that does not match any declared function name.

### Rule description

`ExecuteFunc` takes a function name as a string and executes it at runtime. If the string does not match any function, the call will silently fail at runtime. This diagnostic flags any `ExecuteFunc` string argument that can be evaluated at compile-time.

### How to fix violations

1. Correct the function name string to match an existing function
2. Ensure the target function is declared in the same compilation
3. Consider using `call` statements or `function` references instead of `ExecuteFunc` where possible

### Example

```jass
function Start takes nothing returns nothing
    call ExecuteFunc("NonExistentFunction")
    //               ^^^^^^^^^^^^^^^^^^^^^ JCA1507: No function named 'NonExistentFunction' found
endfunction
```

Fixed code:

```jass
function Start takes nothing returns nothing
    call ExecuteFunc("MyFunction")
endfunction

function MyFunction takes nothing returns nothing
endfunction
```

Alternatively:

```jass
function MyFunction takes nothing returns nothing
endfunction

function Start takes nothing returns nothing
    call MyFunction()
endfunction
```

### When to suppress warnings

Suppress this warning when the target function is defined in a separate file that is not included in the current compilation.
