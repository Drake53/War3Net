## JASS1001: Identifier Expected

| Property       | Value               |
|----------------|---------------------|
| **ID**         | JASS1001            |
| **Descriptor** | IdentifierExpected  |
| **Category**   | Syntax              |
| **Severity**   | Error               |

### Cause

This diagnostic is triggered when the parser expects an identifier (such as a variable name, function name, or type name) but the current token is not an identifier or a keyword.

### Rule description

Many JASS constructs require an identifier in specific positions. For example, function declarations require a function name, variable declarations require a variable name, and type declarations require a type name. When the parser encounters a non-identifier token (such as a number, operator, or symbol) where an identifier is required, this error is reported.

If the token found is a keyword rather than a non-keyword token, [JASS1041](JASS1041.md) is reported instead.

### How to fix violations

1. Add the missing identifier at the expected position
2. Check for typos or misplaced tokens that may have displaced the identifier

### Example

```jass
function takes nothing returns nothing
//       ^^^^^ JASS1001: Identifier expected
endfunction
```

Fixed code:

```jass
function MyFunc takes nothing returns nothing
endfunction
```

Another example:

```jass
globals
    integer = 5
    //      ^ JASS1001: Identifier expected
endglobals
```

Fixed code:

```jass
globals
    integer x = 5
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The missing identifier must be added.
