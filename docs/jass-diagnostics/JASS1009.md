## JASS1009: Invalid Escape Sequence

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS1009              |
| **Descriptor** | InvalidEscapeSequence |
| **Category**   | Syntax                |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when a string, character, or FourCC literal contains an unrecognized escape sequence. Escape sequences begin with a backslash (`\`) followed by a specific character.

### Rule description

JASS supports the following escape sequences in string and character literals:

| Escape | Meaning         |
|--------|-----------------|
| `\\`   | Backslash       |
| `\"`   | Double quote    |
| `\'`   | Single quote    |
| `\n`   | Line feed       |
| `\r`   | Carriage return |
| `\t`   | Tab             |
| `\b`   | Backspace       |
| `\f`   | Form feed       |

Any other character following a backslash is considered an invalid escape sequence.

### How to fix violations

1. Use one of the valid escape sequences listed above
2. If you need a literal backslash, use `\\`
3. If you intended a regular character, remove the backslash

### Example

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("Path: C:\users\name")
    //                       ^^ JASS1009: Invalid escape sequence '\u'
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("Path: C:\\users\\name")
endfunction
```

Another example:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("100\% complete")
    //                  ^^ JASS1009: Invalid escape sequence '\%'
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    call BJDebugMsg("100% complete")
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The escape sequence must be corrected or removed.
