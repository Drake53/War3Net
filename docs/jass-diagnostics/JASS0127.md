## JASS0127: Unexpected Return

| Property       | Value            |
|----------------|------------------|
| **ID**         | JASS0127         |
| **Descriptor** | UnexpectedReturn |
| **Category**   | Semantic         |
| **Severity**   | Error            |

### Cause

This diagnostic is triggered when a function that returns `nothing` attempts to return a value.

### Rule description

In JASS, functions declared with `returns nothing` are procedures that don't return a value. They can use:
- `return` without a value (to exit early)
- No return statement at all (implicit return at end)

They cannot use `return expression` with a value.

### How to fix violations

1. Remove the return value if the function should return nothing
2. Change the function's return type if it should return a value
3. Use early `return` (without value) for control flow

### Example

```jass
function DoWork takes nothing returns nothing
    return 42
    //     ^^ JASS0127: Cannot return a value from function returning 'nothing'
endfunction
```

Fixed code (remove the value):

```jass
function DoWork takes nothing returns nothing
    return
endfunction
```

Or change the return type:

```jass
function DoWork takes nothing returns integer
    return 42
endfunction
```

Conditional return:

```jass
function ProcessData takes integer x returns nothing
    if x < 0 then
        return false
        //     ^^^^^ JASS0127: Cannot return a value from function returning 'nothing'
    endif
    call DoSomething(x)
endfunction
```

Fixed code:

```jass
function ProcessData takes integer x returns nothing
    if x < 0 then
        return  // Early exit, no value
    endif
    call DoSomething(x)
endfunction
```

Or if you need to return success/failure:

```jass
function ProcessData takes integer x returns boolean
    if x < 0 then
        return false
    endif
    call DoSomething(x)
    return true
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Functions returning `nothing` cannot return values.
