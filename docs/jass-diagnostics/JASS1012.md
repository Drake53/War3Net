## JASS1012: Invalid Single-Quoted String Length

| Property       | Value                           |
|----------------|---------------------------------|
| **ID**         | JASS1012                        |
| **Descriptor** | InvalidSingleQuotedStringLength |
| **Category**   | Syntax                          |
| **Severity**   | Error                           |

### Cause

This diagnostic is triggered when a single-quoted literal contains an invalid number of characters. Single-quoted literals must contain exactly 1 character (character literal) or exactly 4 characters (FourCC literal).

### Rule description

JASS supports two kinds of single-quoted literals:

**Character literals:**
- Enclosed in single quotes: `'a'`
- Must contain exactly one character (or escape sequence)

**FourCC literals:**
- Enclosed in single quotes: `'Ahea'`
- Must contain exactly 4 characters

Any other count (0, 2, 3, 5+) is invalid.

### How to fix violations

1. For character literals, ensure exactly one character is between the quotes
2. For FourCC literals, ensure exactly four characters are between the quotes

### Example

```jass
globals
    integer id = 'Ah'
    //           ^^^^ JASS1012: Single-quoted literal ''Ah'' must contain exactly 1 or 4 characters
endglobals
```

Fixed code:

```jass
globals
    integer id = 'Ahea'
endglobals
```

Empty literal example:

```jass
globals
    integer x = ''
    //          ^^ JASS1012: Single-quoted literal '''' must contain exactly 1 or 4 characters
endglobals
```

Fixed code:

```jass
globals
    integer x = 'A'
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The literal must be corrected to have a valid length.
