## JASS0162: Unreachable Code

| Property       | Value           |
|----------------|-----------------|
| **ID**         | JASS0162        |
| **Descriptor** | UnreachableCode |
| **Category**   | CodeQuality     |
| **Severity**   | Warning         |

### Cause

This diagnostic is triggered when code is detected as unreachable due to unconditional exits, exhaustive branching, or compile-time constant conditions. This covers all unreachable code scenarios except root-level return statements, which are reported by JASS0163.

### Rule description

Code can be unreachable for several reasons:

- Statements after `exitwhen true` in a loop
- Statements after an exhaustive `if`/`elseif`/`else` chain where all branches return or exit
- Branches in an `if` statement that can never be reached due to constant conditions (e.g., `if false then`)
- Branches after a constant true condition (e.g., remaining `elseif`/`else` after `if true then`)

### How to fix violations

1. Remove the unreachable code or branch
2. Fix the condition if it should not be constant
3. Restructure the control flow

### Example

Code after unconditional exitwhen:

```jass
function MyFunction takes nothing returns nothing
    loop
        exitwhen true
        call DoSomething()
        //   ^^^^^^^^^^^^^ JASS0162: Unreachable code detected
    endloop
endfunction
```

Unreachable branch:

```jass
function MyFunction takes nothing returns nothing
    if true then
        call DoSomething()
    else
        call DoOther()
        //   ^^^^^^^^^ JASS0162: Unreachable code detected
    endif
endfunction
```

Code after exhaustive if-else with returns:

```jass
function MyFunction takes integer x returns integer
    if x > 0 then
        return 1
    else
        return -1
    endif
    call DoSomething()
    //   ^^^^^^^^^^^^^ JASS0162: Unreachable code detected
endfunction
```

### When to suppress warnings

This warning can be suppressed when the unreachable code is intentional, such as in generated code or when external conditions may vary.
