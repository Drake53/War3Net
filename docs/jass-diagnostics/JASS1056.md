## JASS1056: Invalid Character

| Property       | Value            |
|----------------|------------------|
| **ID**         | JASS1056         |
| **Descriptor** | InvalidCharacter |
| **Category**   | Syntax           |
| **Severity**   | Error            |

### Cause

This diagnostic is triggered when the lexer encounters a character that is not valid in JASS source code.

### Rule description

JASS only recognizes a specific set of characters outside of string, character, and FourCC literals. Valid characters include:

- Letters (`a`-`z`, `A`-`Z`), digits (`0`-`9`), and underscores (`_`) for identifiers
- Digits (`0`-`9`, `a`-`f`) and dots (`.`) numeric literals
- Hexadecimal prefix: `0x` or `$`
- Operators: `+`, `-`, `*`, `/`, `=`, `<`, `>`, `!` (only as part of `!=`)
- Delimiters: `(`, `)`, `[`, `]`, `,`
- String, character, and FourCC delimiters: `"`, `'`
- Whitespace: spaces, tabs, carriage returns, line feeds

Any other character encountered outside of a string, character, or FourCC literal is reported as invalid. The `!` character is also reported as invalid when used as a standalone operator (it is only valid as part of the `!=` operator).

The message format is `Invalid character '{0}'`, where `{0}` is the invalid character.

### How to fix violations

1. Remove the invalid character from the source code
2. If the character was intended to be inside a string, enclose it in quotes
3. Replace the character with the correct JASS equivalent (e.g., use `not` instead of `!` for logical negation)

### Example

```jass
function Test takes nothing returns nothing
    if !condition then
    // ^ JASS1056: Invalid character '!'
    endif
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    if not condition then
    endif
endfunction
```

Another example:

```jass
globals
    integer x = 5 & 3
    //            ^ JASS1056: Invalid character '&'
endglobals
```

Fixed code:

```jass
globals
    integer x = 5
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The invalid character must be removed or replaced.
