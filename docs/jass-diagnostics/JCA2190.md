## JASS2910: Infinite Loop

| Property       | Value        |
|----------------|--------------|
| **ID**         | JASS2910     |
| **Descriptor** | InfiniteLoop |
| **Category**   | CodeQuality  |
| **Severity**   | Warning      |

### Cause

This diagnostic is triggered when a loop has no reachable `exitwhen` or `return` statement, meaning it has no way to terminate.

### Rule description

In Warcraft III, an infinite loop gets terminated automatically by the JASS VM if its execution count reaches a certain threshold, preventing the game from freezing. However, depending on how often the loop runs, this can significantly impact the game's performance. Every loop should have at least one `exitwhen` statement or a `return` statement to provide a termination condition.

### How to fix violations

1. Add an `exitwhen` statement with an appropriate condition
2. Add a `return` statement inside the loop
3. Verify the loop logic includes a reachable exit path

### Example

```jass
function Process takes nothing returns nothing
    local integer i = 0
    loop
//  ^^^^ JASS2910: Loop may be infinite; no exit condition found
        set i = i + 1
    endloop
endfunction
```

Fixed code:

```jass
function Process takes nothing returns nothing
    local integer i = 0
    loop
        exitwhen i >= 100
        set i = i + 1
    endloop
endfunction
```

### When to suppress warnings

This warning should not be suppressed. A loop should always contain an exit condition.
