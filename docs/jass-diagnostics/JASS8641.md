## JASS8641: Else Without If

| Property       | Value         |
|----------------|---------------|
| **ID**         | JASS8641      |
| **Descriptor** | ElseWithoutIf |
| **Category**   | Syntax        |
| **Severity**   | Error         |

### Cause

This diagnostic is triggered when an `else` or `elseif` clause appears without a preceding `if` statement.

### Rule description

In JASS, `else` and `elseif` clauses must appear within an `if`...`endif` block. A stray `else` or `elseif` outside of an `if` statement is invalid.

```jass
if condition then
    // statements
elseif otherCondition then
    // statements
else
    // statements
endif
```

### How to fix violations

Ensure `else` and `elseif` clauses are placed inside a matching `if` statement.

### Example

```jass
function MyFunction takes nothing returns nothing
    if true then
        call A()
    endif
    else
        call B()
    endif
// JASS8641: 'else' without matching 'if'
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    if true then
        call A()
    else
        call B()
    endif
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Every `else` and `elseif` must be inside a matching `if` statement.
