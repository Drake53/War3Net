## JASS8641: Else Without If

| Property       | Value         |
|----------------|---------------|
| **ID**         | JASS8641      |
| **Descriptor** | ElseWithoutIf |
| **Category**   | Syntax        |
| **Severity**   | Error         |

### Cause

This diagnostic is triggered when an `else` or `elseif` clause appears without a valid matching `if` statement. This includes:

- A stray `else` or `elseif` outside of any `if` block
- An `else` or `elseif` after `endif` (no longer inside an `if`)
- A duplicate `else` clause (the first `else` already consumed the slot)
- An `elseif` appearing after an `else` clause

### Rule description

In JASS, `else` and `elseif` clauses must appear within an `if`...`endif` block, and each `if` statement allows at most one `else` clause which must be the final branch:

```jass
if condition then
    // statements
elseif otherCondition then
    // statements
else
    // statements
endif
```

### How to fix violations

Ensure `else` and `elseif` clauses are placed inside a matching `if` statement, with `else` appearing only once and as the last branch before `endif`.

### Examples

Stray `else` after `endif`:

```jass
function MyFunction takes nothing returns nothing
    if true then
        call A()
    endif
    else
        call B()
    endif
// JASS8641: 'else' without matching 'if'
```

Duplicate `else`:

```jass
function MyFunction takes nothing returns nothing
    if x > 10 then
        call DoA()
    else
        call DoB()
    else
//  ^^^^ JASS8641: 'else' without matching 'if'
        call DoC()
    endif
endfunction
```

`elseif` after `else`:

```jass
function MyFunction takes nothing returns nothing
    if x > 10 then
        call DoA()
    else
        call DoB()
    elseif x > 5 then
//  ^^^^^^ JASS8641: 'elseif' without matching 'if'
        call DoC()
    endif
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Every `else` and `elseif` must be inside a matching `if` statement.
