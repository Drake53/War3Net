## JASS8641: Unmatched Block Keyword

| Property       | Value                 |
|----------------|-----------------------|
| **ID**         | JASS8641              |
| **Descriptor** | UnmatchedBlockKeyword |
| **Category**   | Syntax                |
| **Severity**   | Error                 |

### Cause

This diagnostic is triggered when a block-delimiter keyword appears without a matching opening keyword. This covers both:

- A block-end keyword (`endfunction`, `endglobals`, `endif`, or `endloop`) with no open block to close.
- An `else` or `elseif` clause with no matching `if`. This includes:
  - A stray `else` or `elseif` outside of any `if` block
  - An `else` or `elseif` after `endif` (no longer inside an `if`)
  - A duplicate `else` clause (the first `else` already consumed the slot)
  - An `elseif` appearing after an `else` clause

### Rule description

Every block keyword must pair with its matching opener:

| Block keyword       | Matching opening keyword |
|---------------------|--------------------------|
| `endfunction`       | `function`               |
| `endglobals`        | `globals`                |
| `endif`             | `if`                     |
| `endloop`           | `loop`                   |
| `else` / `elseif`   | `if`                     |

In JASS, `else` and `elseif` clauses must appear within an `if`...`endif` block, and each `if` statement allows at most one `else` clause which must be the final branch:

```jass
if condition then
    // statements
elseif otherCondition then
    // statements
else
    // statements
endif
```

### How to fix violations

Remove the stray keyword, or add the missing opening keyword for the block it was meant to close. Ensure `else` and `elseif` clauses are placed inside a matching `if` statement, with `else` appearing only once and as the last branch before `endif`.

### Examples

Stray `endloop` without an open `loop`:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething()
    endloop
//  ^^^^^^^ JASS8641: 'endloop' without matching 'loop'
endfunction
```

Duplicate `endif`:

```jass
function MyFunction takes nothing returns nothing
    if true then
        call DoSomething()
    endif
    endif
//  ^^^^^ JASS8641: 'endif' without matching 'if'
endfunction
```

Stray `endfunction` at top level:

```jass
function MyFunction takes nothing returns nothing
endfunction
endfunction
// ^^^^^^^^ JASS8641: 'endfunction' without matching 'function'
```

Stray `else` after `endif`:

```jass
function MyFunction takes nothing returns nothing
    if true then
        call A()
    endif
    else
//  ^^^^ JASS8641: 'else' without matching 'if'
        call B()
    endif
endfunction
```

Duplicate `else`:

```jass
function MyFunction takes nothing returns nothing
    if x > 10 then
        call DoA()
    else
        call DoB()
    else
//  ^^^^ JASS8641: 'else' without matching 'if'
        call DoC()
    endif
endfunction
```

`elseif` after `else`:

```jass
function MyFunction takes nothing returns nothing
    if x > 10 then
        call DoA()
    else
        call DoB()
    elseif x > 5 then
//  ^^^^^^ JASS8641: 'elseif' without matching 'if'
        call DoC()
    endif
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Every block keyword must pair with a matching opener.
