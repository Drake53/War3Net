## JASS5001: Missing Entry Point Function

| Property       | Value             |
|----------------|-------------------|
| **ID**         | JASS5001          |
| **Descriptor** | MissingEntryPoint |
| **Category**   | Semantic          |
| **Severity**   | Error             |

### Cause

A Warcraft III map script (`war3map.j`) does not declare one of the required entry point functions, `main` or `config`.

### Rule description

The Warcraft III engine calls two functions when loading a map:

- `config` — runs first, to report the map's metadata (name, player slots, etc.) to the game lobby.
- `main` — runs when the map starts, to initialize the game world.

Both must exist in `war3map.j`. This diagnostic is reported once for each missing function.

This diagnostic is **only** reported when the source file is named `war3map.j`.

### How to fix violations

Declare the missing entry point function with the signature `takes nothing returns nothing`.

### Example

```jass
// war3map.j
function config takes nothing returns nothing
endfunction
// JASS5001: Map script is missing entry point function 'main'
```

Fixed code:

```jass
// war3map.j
function config takes nothing returns nothing
endfunction

function main takes nothing returns nothing
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. A map script without both entry points will not load in-game.
