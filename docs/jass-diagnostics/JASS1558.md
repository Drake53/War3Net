## JASS1558: Unsuitable Entry Point Function

| Property       | Value                |
|----------------|----------------------|
| **ID**         | JASS1558             |
| **Descriptor** | UnsuitableEntryPoint |
| **Category**   | Semantic             |
| **Severity**   | Error                |

### Cause

A symbol named `main` or `config` exists in a map script (`war3map.j`), but it cannot serve as an entry point because it is declared as a `native` or a `constant` function.

### Rule description

The Warcraft III engine calls `main` and `config` to configure and start the map. To do this they must be ordinary functions:

- A `native` function has no body the map script can provide, so it cannot be the entry point.
- A `constant` function may not modify globals or call non-constant functions, but `main` and `config` exist precisely to call the non-constant natives that set up the map. A `constant` entry point is therefore never valid.

This diagnostic is **only** reported when the source file is named `war3map.j`.

### How to fix violations

Declare the entry point as an ordinary (non-native, non-constant) function with the signature `takes nothing returns nothing`.

### Example

```jass
// war3map.j
constant function main takes nothing returns nothing
//                ^^^^ JASS1558: 'main' is not a suitable entry point function
endfunction
```

Fixed code:

```jass
// war3map.j
function main takes nothing returns nothing
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. An unsuitable entry point cannot be invoked by the game engine.
