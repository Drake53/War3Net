## JASS1041: Identifier Expected; Keyword Found

| Property       | Value                      |
|----------------|----------------------------|
| **ID**         | JASS1041                   |
| **Descriptor** | IdentifierExpectedKeyword  |
| **Category**   | Syntax                     |
| **Severity**   | Error                      |

### Cause

This diagnostic is triggered when the parser expects an identifier but encounters a JASS keyword instead. Keywords are reserved words and cannot be used as identifiers.

### Rule description

JASS reserves certain words as keywords that have special meaning in the language. These include type keywords (`boolean`, `integer`, `real`, `string`, `handle`, `code`), control flow keywords (`if`, `then`, `else`, `elseif`, `endif`, `loop`, `endloop`, `exitwhen`, `return`), declaration keywords (`function`, `endfunction`, `globals`, `endglobals`, `local`, `set`, `call`, `takes`, `returns`, `nothing`, `constant`, `native`, `type`, `extends`, `array`), literal keywords (`true`, `false`, `null`), and operator keywords (`not`, `and`, `or`).

Keywords cannot be used as names for functions, variables, parameters, or types.

The message format is `Identifier expected; '{0}' is a keyword`, where `{0}` is the keyword that was found.

### How to fix violations

1. Choose a different name that is not a reserved keyword
2. If the keyword was placed accidentally, replace it with the intended identifier

### Example

```jass
function Test takes nothing returns nothing
    local integer set = 5
    //            ^^^ JASS1041: Identifier expected; 'set' is a keyword
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    local integer value = 5
endfunction
```

Another example:

```jass
function nothing takes nothing returns nothing
//       ^^^^^^^ JASS1041: Identifier expected; 'nothing' is a keyword
endfunction
```

Fixed code:

```jass
function DoNothing takes nothing returns nothing
endfunction
```

Another example:

```jass
function Test takes nothing returns nothing
    local integer function = 5
    //            ^^^^^^^^ JASS1041: Identifier expected; 'function' is a keyword
endfunction
```

Fixed code:

```jass
function Test takes nothing returns nothing
    local integer funcValue = 5
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The identifier must be renamed to a non-keyword.
