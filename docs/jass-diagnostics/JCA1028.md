## JASS2928: Trailing Whitespace

| Property       | Value              |
|----------------|--------------------|
| **ID**         | JASS2928           |
| **Descriptor** | TrailingWhitespace |
| **Category**   | Style              |
| **Severity**   | Warning            |

### Cause

This diagnostic is triggered when a line ends with whitespace characters (spaces or tabs) after the code content.

### Rule description

Trailing whitespace is problematic because:
- It's invisible and serves no purpose
- It creates unnecessary differences in version control
- It can cause issues with some tools
- It indicates sloppy formatting

### How to fix violations

1. Remove trailing spaces and tabs from line endings
2. Configure your editor to trim trailing whitespace on save
3. Use a code formatter that removes trailing whitespace

### Example

```jass
function MyFunction takes nothing returns nothing	
    call DoWork()  
    // Lines above have trailing spaces (invisible)
    // JASS2928: Trailing whitespace
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call DoWork()
endfunction
```

### When to suppress warnings

Suppress this warning when:
- Working with files that must preserve exact whitespace
