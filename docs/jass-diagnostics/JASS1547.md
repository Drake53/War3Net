## JASS1547: Nothing Not Allowed

| Property       | Value             |
|----------------|-------------------|
| **ID**         | JASS1547          |
| **Descriptor** | NothingNotAllowed |
| **Category**   | Semantic          |
| **Severity**   | Error             |

### Cause

This diagnostic is triggered when the keyword `nothing` is used in a context where it's not allowed.

### Rule description

The `nothing` type in JASS has very limited valid uses:
- As a function return type to indicate the function doesn't return a value
- In `takes nothing` to indicate a function has no parameters

`nothing` cannot be used:
- As a variable type (local or global)
- As an array element type
- As a parameter type (use `takes nothing` for no parameters)
- As a base type in a type declaration

### How to fix violations

1. Use an appropriate type for the variable or parameter
2. For "no value" scenarios with handles, use the `null` literal instead
3. If you need a generic container, use `handle` type

### Example

```jass
globals
    nothing myVar
//  ^^^^^^^ JASS1547: Keyword 'nothing' cannot be used in this context
endglobals
```

Fixed code:

```jass
// Remove the variable or use a valid type
globals
    handle myVar = null
endglobals
```

Parameter example:

```jass
function MyFunction takes integer a, nothing b returns nothing
//                                   ^^^^^^^ JASS1547: Keyword 'nothing' cannot be used in this context
endfunction
```

Fixed code:

```jass
function MyFunction takes integer a, handle b returns nothing
endfunction
```

Array example:

```jass
globals
    nothing array myArray
//  ^^^^^^^ JASS1547: Keyword 'nothing' cannot be used in this context
endglobals
```

Fixed code:

```jass
globals
    handle array myArray
endglobals
```

Type extension example:

```jass
type myvoid extends nothing
//                  ^^^^^^^ JASS1547: Keyword 'nothing' cannot be used in this context
```

Fixed code:

```jass
type myvoid extends handle
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. The `nothing` type can only be used in function signatures.
