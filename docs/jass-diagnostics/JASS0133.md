## JASS0133: Constant Initializer Not Constant

| Property       | Value                          |
|----------------|--------------------------------|
| **ID**         | JASS0133                       |
| **Descriptor** | ConstantInitializerNotConstant |
| **Category**   | Semantic                       |
| **Severity**   | Error                          |

### Cause

This diagnostic is triggered when a constant is initialized with an expression that that is not constant.

### Rule description

In JASS, constants must be initialized with constant expressions. Valid constant initializers include:
- Literal values (`5`, `3.14`, `"hello"`, `true`, `'Ahea'`)
- Unary and binary expressions where the operands are constant expressions
- Expressions that invoke a constant function or native
- References to a variable, array, or function

Basically, everything that does not invoke a non-constant function or native is a constant expression.

### How to fix violations

1. Use a literal value or other constants in the initializer
2. Change to a non-constant variable if runtime initialization is needed
3. Use a constant function for computed values

### Example

```jass
function GetDefaultSize takes nothing returns integer
    return 10
endfunction

globals
    constant integer SIZE = GetDefaultSize()
    //                      ^^^^^^^^^^^^^^^^ JASS0133: Constant initializer must be a constant expression
endglobals
```

Fixed code (use literal):

```jass
globals
    constant integer SIZE = 10
endglobals
```

Or use a constant function:

```jass
constant function GetDefaultSize takes nothing returns integer
    return 10
endfunction

globals
    constant integer SIZE = GetDefaultSize()
endglobals
```

Using other constants (valid):

```jass
globals
    constant integer BASE = 10
    constant integer MULTIPLIER = 2
    constant integer TOTAL = BASE * MULTIPLIER
endglobals
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Constant initializers must use a constant expression.
