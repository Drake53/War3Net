## JASS1958: Code Type Not Allowed

| Property       | Value              |
|----------------|--------------------|
| **ID**         | JASS1958           |
| **Descriptor** | CodeTypeNotAllowed |
| **Category**   | Semantic           |
| **Severity**   | Error              |

### Cause

This diagnostic is triggered when the `code` type is used in an array declaration. JASS does not support arrays of code (function pointers).

### Rule description

The `code` type in JASS represents a function reference (function pointer). While `code` can be used for:
- Function parameters
- Global/local variables
- Function return types

It cannot be used for:
- Array declarations (`code array` is not supported)

### How to fix violations

1. Use a design pattern that doesn't require arrays of functions
2. Use a switch/if-else structure to select functions
3. Store function identifiers as integers and map them to functions

### Example

```jass
globals
    code array callbacks
    //   ^^^^^ JASS1958: Type 'code' cannot be used for arrays
endglobals
```

Fixed code (using alternative design):

```jass
globals
    code callback1
    code callback2
    code callback3
endglobals

function GetCallback takes integer index returns code
    if index == 0 then
        return callback1
    elseif index == 1 then
        return callback2
    else
        return callback3
    endif
endfunction
```

Local array example:

```jass
function MyFunction takes nothing returns nothing
    local code array funcs
    //         ^^^^^ JASS1958: Type 'code' cannot be used for arrays
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    local code func1
    local code func2
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Arrays of `code` type are not supported in JASS.
