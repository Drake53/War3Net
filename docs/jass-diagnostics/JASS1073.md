## JASS1073: Unexpected Token

| Property       | Value           |
|----------------|-----------------|
| **ID**         | JASS1073        |
| **Descriptor** | UnexpectedToken |
| **Category**   | Syntax          |
| **Severity**   | Error           |

### Cause

This diagnostic is triggered when an unexpected token is encountered that does not belong in the current context. For example, an `endif` without a matching `if`, an `endloop` without a matching `loop`, an `endfunction` without a matching `function`, or an `endglobals` without a matching `globals`.

### Rule description

In JASS, block-closing keywords must have a corresponding opening keyword. An orphaned closing keyword indicates either a missing opener or an extra closer.

### How to fix violations

1. Remove the extra keyword if there is no corresponding opening statement
2. Add the missing opening statement
3. Check if the closing keyword was accidentally duplicated

### Example

```jass
function MyFunction takes nothing returns nothing
    call DoSomething()
    endif
 // ^^^^^ JASS1073: Unexpected token 'endif'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething()
endfunction
```

Duplicate endloop example:

```jass
function MyFunction takes nothing returns nothing
    loop
        exitwhen true
    endloop
    endloop
 // ^^^^^^^ JASS1073: Unexpected token 'endloop'
endfunction
```

Fixed code:

```jass
function MyFunction takes nothing returns nothing
    loop
        exitwhen true
    endloop
endfunction
```

Orphaned endfunction example:

```jass
function MyFunction takes nothing returns nothing
    call DoSomething()
endfunction
endfunction
// ^^^^^^^^^^^ JASS1073: Unexpected token 'endfunction'
```

Orphaned endglobals example:

```jass
globals
    integer x = 5
endglobals
endglobals
// ^^^^^^^^^^ JASS1073: Unexpected token 'endglobals'
```

Stray endglobals inside a function body:

```jass
function foo takes nothing returns nothing
    endglobals
 // ^^^^^^^^^^ JASS1073: Unexpected token 'endglobals'
endfunction
```

Globals block inside function:

```jass
function MyFunction takes nothing returns nothing
    globals
    // ^^^^^^^ JASS1073: 'globals' block must be at top level
        integer x = 5
    endglobals
endfunction
```

Fixed code:

```jass
globals
    integer x = 5
endglobals

function MyFunction takes nothing returns nothing
    // Use local variables inside functions
    local integer y = x + 1
endfunction
```

### When to suppress warnings

This is a compiler error and cannot be suppressed. Every closing keyword must have a matching opening keyword.
